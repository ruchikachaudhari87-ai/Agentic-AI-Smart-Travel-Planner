# Agentic AI-Based Personalized Smart Travel Planner

## Project Description
This project aims to develop an AI-based travel planner that generates personalized travel itineraries according to user preferences, budget, destination, and trip duration.

## Technologies Used
- Python
- Flask
- HTML and CSS
- Agentic AI
- Dataset (CSV)
- SQLite Database

## Planned Features
- Personalized itinerary generation
- Destination recommendations
- Budget-based travel planning
- Crowd information integration
- Traffic information integration

## Project Status
Development in progress.
